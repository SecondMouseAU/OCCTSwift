# Second seeding of the Swift exemption manifest (#2852), 2026-09-30.
#
# Scripts/style-manifest-swift.txt was seeded with Sources/OCCTSwift alone, because that was the
# only directory code-style.yml's swift-format step walked. That step now walks every tracked
# Swift file in the repo. This file holds the files that widening newly reached and that
# `swift-format lint --strict --configuration .swift-format` rejected on the day it was widened:
# 418 of the 1,500 tracked .swift files outside Sources/OCCTSwift.
#
# The rules are the other manifest's, unchanged and enforced by the same
# Scripts/check-style-manifest.py: a listed file is exempt until you touch it, touching it means
# fixing it and deleting its line here in the same PR, and the list may only shrink. A file that
# is not listed complies from creation.
#
# It is a separate file rather than more lines in style-manifest-swift.txt because the shrink rule
# forbids growing an existing manifest: a manifest absent at the base ref is being seeded, which
# is allowed, and one that gains an entry is grandfathering something new, which is not. See that
# script's read_manifest_at docstring.
#
# 146 of the 418 needed nothing but `swift-format format -i`; they are formatted and delisted in
# the next commit of this issue's own PR, so what is left here is the residue that needs prose
# edited rather than lines rewrapped: 607 BeginDocumentationCommentWithOneLineSummary,
# 12 EndOfLineComment, 12 AlwaysUseLowerCamelCase, 4 ReplaceForEachWithForLoop, and 2 each of
# ValidateDocumentationComments, NoBlockComments and OneCasePerLine.
#
# The Scripts/repro/ entries below are a different kind of listing and will not shrink the
# way the rest do. They are frozen evidence: standalone probes kept so a measurement can be
# repeated, several of them attached to an upstream report. `swift-format format -i` rewrote
# ten of them in this issue's own PR and the change was reverted, because one of the
# rewrites deleted `-> Void` from the two functions in #1057's minimal reproducer, whose
# whole point is to pin the exact shape swift-testing's macro expands to for
# swiftlang/swift#91639. A reformatted reproducer that stops reproducing reads as "fixed
# upstream". Retire one by deleting the probe when its issue closes, not by formatting it.
#
