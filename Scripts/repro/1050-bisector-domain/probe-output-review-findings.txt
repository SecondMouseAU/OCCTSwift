f3  every way an empty result arises, derived rather than enumerated by hand

  The reference doc has undercounted this list twice. Each row below is a distinct
  branch that ends in an empty array, with the mechanism that produced it.

  input                                    NbPoints   NbSegs     threw     mechanism
  first pair coincident (a == b)           0          0          yes       no bisector exists, Normalize() refuses
  second pair coincident (c == d)          0          0          yes       no bisector exists, Normalize() refuses
  bisectors parallel and distinct          0          0          no        no crossing exists
  bisectors cross off the kept ray         0          0          no        crossing is behind a midpoint
  bisectors coincide                       0          1          no        overlap reported as a segment, #1070
  a real crossing, for contrast            1          0          no        found, not empty

  Four causes, and the partition is closed by construction rather than by inspection:
  either a bisector does not exist (a coincident pair, rows 1 and 2), or both do, and
  then the two underlying lines are parallel-distinct (row 3), identical (row 5), or
  cross at exactly one point, which is on both kept rays or is not (row 4).
